# Handwritten Scientific Readability

This project implements a computational framework to quantify and evaluate the structural machine readability of handwritten scientific documents. The goal is to provide tools and methodologies for analyzing handwritten texts, making them more accessible and usable in digital formats.

## Installation

To install the required dependencies, run:

```
pip install -r requirements.txt
```

Install Tesseract separately on Windows and make sure this path exists, or pass your own path with `--tesseract-cmd`:

```
C:\Program Files\Tesseract-OCR\tesseract.exe
```

Create a `ground_truth/` directory with one `.txt` file per image in `notebookimages/`, using the same basename. For example, `notebookimages/neat.png` should pair with `ground_truth/neat.txt`.

Put notebook PDFs in `pdfs/` so they stay separate from the page images. For example, `pdfs/notebook.pdf`.

## Usage

To run the application, execute the following command:

```
python src/app.py
```

To generate OCR validation results:

```
python src/validate_tesseract.py --image-folder notebookimages --ground-truth-dir ground_truth
```

To compare OCR results with the structural metrics produced by this project:

```
python src/compare_results.py --image-folder notebookimages --ground-truth-dir ground_truth
```

This writes both `comparison_results.csv` and `comparison_summary.csv` by default.

To compare a single representative PNG against OCR of a whole PDF notebook:

```
python src/app.py notebookimages/neat.png --pdf-path pdfs/notebook.pdf --ground-truth-file ground_truth/notebook.txt
```

The PDF OCR path uses PyMuPDF to render pages and Tesseract to extract the text before computing CER.
The ground-truth text file is not generated by Tesseract; it should be a manual transcription you provide for comparison.

If you do not want to create a manual transcript, omit `--ground-truth-file`. The run will create a visual review package in `review_outputs/` with the extracted PDF text and skip CER.
The review package also includes per-page character counts and a total character count so you can quickly spot-check page lengths while reviewing.
Every PDF page is also rendered automatically as a PNG in `review_outputs/rendered_pages/`. Use `--render-dir` to choose a different output folder.
